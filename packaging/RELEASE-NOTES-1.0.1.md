# Rime VMenu 全家桶 1.0.1

**本版专治一件事：语音识别时 CPU 被打满。**

两个包**功能完全一致**，按喜好选一个下载即可。

## 下载哪个？

| 文件 | 适合谁 | 怎么装 |
| --- | --- | --- |
| **`RimeVMenu-Setup-1.0.1.exe`**（1.1 GB） | 大多数人 | 双击 → 一路下一步。自动识别你的小狼毫用户目录、装好后台服务、托盘入口，并自动部署 |
| **`RimeVMenu-1.0.1.zip`**（1.1 GB） | 想手动/绿色安装，或用小狼毫官方 `rime-install` 导入配置 | 解压后双击 **`安装.bat`**；只更新配置见下方说明 |

> 首次安装会带 **971 MB 语音模型**（Qwen3-ASR，本地离线推理），所以包体积大。不想要语音功能可以装完后删掉安装目录里的两个 `*.gguf`。

## 本版修了什么

### 语音识别不再把 CPU 打满（主要原因）

按住 `Ctrl+Win` 说话时，任务管理器会瞬间飙红——**这是 llama.cpp 默认参数导致的**，
跟你的机器性能无关。

llama.cpp 默认用 `-t -1`，即**按逻辑核数开线程**。在 16 逻辑核的机器上，
每次识别都会瞬间开满 16 个线程做空转自旋同步，于是任务管理器里就是一条直线冲顶。

实测（i7-13620H / 16 逻辑核，识别同一段 6.2 秒中文语音）：

| 指标 | 1.0.0（默认 16 线程） | 1.0.1（4 线程） |
| --- | --- | --- |
| 平均整机 CPU | **59.1%** | **20.7%** |
| 瞬时峰值 | **78%（打满）** | **38.7%** |
| 识别耗时 | 0.52 s | 0.59 s（+70 ms，无感） |
| **总 CPU 消耗** | 2.16 s | **1.94 s（反而更少）** |
| 识别结果 | `今天天气真好，我们去公园散步吧。` | **完全一致** |

关键点有两个：

1. **限制线程不会变慢，反而更省电。** 超过物理核的线程纯粹在空转自旋，
   实测把线程从 16 降到 4，**总 CPU 消耗从 2.16 s 降到 1.94 s**，
   而墙钟只多了 70 毫秒——省掉的是线程同步开销，不是算力。
2. **识别率零损失。** 模型权重一个字没改，只是并行度不同，所以准确率完全不变。

### 可以自己调了

设置窗口 →「语音输入」页新增 **「语音识别 CPU 占用」** 卡片，滑块范围 1 ～ 物理核数
（自动检测，本机为 10），实时显示预估占用档位：

| 线程数 | 整机 CPU 约 |
| --- | --- |
| 2 | 12% |
| **4（默认）** | **26%** |
| 6 | 36% |
| 8+ | 48% 以上，不再推荐 |

滑块底下直接写了「超过物理核只会空转自旋，越开越慢」。
改完**重新打开一次语音输入**（或重启悬浮球）即生效。

不想开设置窗口也可以直接改 `<你的小狼毫用户目录>\voice-settings.txt`：

```ini
asr_threads=4
```

填 `0`、`999`、`abc` 这类非法值会自动退回默认 4，不会把机器打死。

## 装好的功能

- **`v` 功能菜单** —— 输入法里按 `v`：设置窗口 / 剪贴板 / 快捷输入（计算、日期、农历、序号…）/ 常用语 / 原符号
- **可视化设置窗口**（原生 `VMenuSettings.exe`）—— 词库管理、剪贴板、模糊音开关、语音快捷键、防误触、语音 CPU 占用，改完即生效
- **剪贴板历史** —— 后台自动记录，`v` → `2` 调用
- **常用语 / 个人词库** —— 设置窗口直接增删改，或用 `加词.bat` / `词库管理.bat`
- **下一个候选词预测** —— 字级二元统计，打完一个字就提示下一个
- **前后鼻音模糊输入** —— an/ang、en/eng、in/ing、ian/iang、uan/uang 五对可单独开关
- **本地语音输入** —— 按住 `Ctrl+Win` 说话、松开上屏，流式输出，全程离线
- **候选框增强** —— 一行 9 个候选，按 `↓` 展开 4×9 方格，长英文自动截断
- **托盘入口** —— 右键托盘图标 →「输入法设置 (S)」

## 环境要求

- Windows 10 / 11 x64
- 小狼毫 [Weasel](https://github.com/rime/weasel)（exe 包在检测不到时会自动拉起内置的 0.17.4 安装器）
- 全程**不需要管理员权限**（装进用户目录、只写 `HKCU`）
- 语音走 CPU 推理即可用；有 N 卡可换 llama.cpp 的 CUDA 版 `llama-server.exe` 提速

## 升级方式

**从 1.0.0 升上来直接覆盖安装即可**，词库、常用语、剪贴板历史都会保留。
安装前会自动停掉正在占用模型的 `llama-server.exe`，不会出现「文件被占用装不上」。

## zip 用户：只想更新配置（方式 C）

小狼毫自带 `rime-install.bat` 可直接吃本 zip，但遵守官方规则：**只复制顶层 `*.yaml`、`*.txt` 和 `opencc\`**，
不复制 `lua\`、`cn_dicts\` 和外挂 exe —— 适合给已部署好的机器覆盖更新配置。

```bat
"C:\Program Files\Rime\weasel-0.17.4\rime-install.bat" C:\RimePkg\RimeVMenu-1.0.1.zip
```

> ⚠️ zip 路径**不能有空格、也不能加引号**（`rime-install.bat` 自身解析不了，会报 batch 语法错或误当成包名去 GitHub 下载）。请先把 zip 挪到无空格目录。

**你自己的词库、常用语、剪贴板历史会保留**（已实测）。
